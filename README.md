# ✈️ Jadoo – Travel Website

A modern, responsive travel website built with **React.js, Vite, Tailwind CSS, and Framer Motion**. Jadoo provides an engaging travel experience with destination showcases, service sections, customer testimonials, and smooth animations.

## 🌐 Live Demo

**Live Website:** https://jadoo-plum-seven.vercel.app/

**GitHub Repository:** https://github.com/Dattatray1705/Jadoo

---

## 📸 Project Overview

Jadoo is a travel landing page designed to present travel destinations, services, customer experiences, and travel-related information through a clean and responsive user interface.

The project focuses on reusable React components, responsive layouts, visual design, and smooth user interactions.

## ✨ Features

- **Responsive Design** – Layout adapts to mobile, tablet, and desktop screens.
- **Hero Section** – Attractive travel landing section.
- **Services Section** – Displays travel services using custom image assets.
- **Top Destinations** – Showcases destination cards with decorative elements.
- **Booking Steps** – Presents the travel booking process.
- **Testimonials** – Dedicated section for customer reviews.
- **Partner Logos** – Displays travel partner images.
- **Newsletter Section** – Newsletter subscription UI.
- **Footer Section** – Company information and navigation visuals.
- **Smooth Animations** – Framer Motion animations and hover effects.
- **Reusable Components** – Website sections are organized into separate React components.

## ⚙️ Installation and Setup

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git (optional, for cloning the repository)

### 1. Clone the Repository

```bash
git clone https://github.com/Dattatray1705/Jadoo.git
```

### 2. Navigate to the Project Directory

```bash
cd Jadoo
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```

### 5. Create a Production Build

```bash
npm run build
```

### 6. Preview the Production Build

```bash
npm run preview
```

## 🚀 Deployment

The website is deployed using Vercel.

**Live URL:** https://jadoo-plum-seven.vercel.app/

To deploy your own version:

1. Push the source code to GitHub.
2. Import the repository into Vercel.
3. Select Vite as the framework preset.
4. Set the build command to `npm run build`.
5. Set the output directory to `dist`.
6. Click **Deploy**.
